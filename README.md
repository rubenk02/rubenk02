## 🚀 Selected Projects

### 🎾 Tennis Player Performance Analysis

A Python-based data analysis project examining the factors that influence match outcomes among top professional tennis players.

The project combines match histories, ATP rankings, Elo-based player selection, and surface-specific player statistics to investigate:

* How strongly rankings influence match outcomes
* How player performance changes across clay, grass, and hard courts
* Which player characteristics are associated with winning
* How frequently lower-ranked players produce upsets

**Technical focus:** Python, pandas, data cleaning, web scraping, feature engineering, statistical analysis, and data visualization.
